# Контракт sanitize

Команда отделяет текст, который виден на странице, от текста, который парсер достаёт из скрытого слоя. Модели отдаётся только первое. Отчёт о находках остаётся человеку: строка атаки в отчёте сама может быть инструкцией.

## Уровни

Уровень задаёт человек в `.sanitize/config.json` домашнего каталога. Агент не понижает его. Файл в репозитории не читается: иначе чужой проект мог бы отключить проверку.

| Уровень | Что меняется в model.json | Что попадает в evidence.json |
|---|---|---|
| 0 | Скрытые слои формата удержаны | Эти слои |
| 1 | Плюс сняты невидимые символы Unicode | Плюс метка о символах |
| 2 (по умолчанию) | То же, что 1 | Плюс эвристики по видимому тексту, без вырезания |
| 3 | То же, что 2 | Плюс пометка классификатора, если задан хук |
| 4 | Из видимого текста вырезаны фразы эвристик | Плюс список вырезанного |

Классификатор и список фраз не делают файл «плохим» и не меняют видимый текст на уровнях 0–3. Вердикт `hidden_mismatch` ставит только код, который нашёл скрытый слой.

Хук классификатора: переменная `SANITIZE_CLASSIFIER=module:function`. Функция получает кусок текста и возвращает `{"label": "...", "score": 0.0}`. Пометка появляется при `score >= 0.5` или метке со словами injection, jailbreak, malicious.

## Файлы результата

`model.json` можно класть в контекст:

- `visible_text` — текст страницы
- `auxiliary` — подпись слайда, заметки докладчика, комментарии Word, title HTML
- `spotlight` — те же данные внутри маркеров `<<<UNTRUSTED_DATA ...>>>`
- `flags.hidden_withheld` — скрытый слой удержан
- `flags.render_unverified` — слой PDF оставлен без сравнения с картинкой
- `instruction` — постоянная фраза, не из документа

`evidence.json` только человеку. Там вердикт, категории и короткие выдержки. `visible.txt` равен `visible_text`.

Вердикты:

- `clean` — модели отдано то, что и так видно
- `marked` — есть пометка (эвристика, Unicode без отдельного сообщения, строгий уровень)
- `hidden_mismatch` — скрытый текст не совпал с видимым и удержан

## Журналы

Оба лежат в домашнем `.sanitize/`. В записи нет текста документа.

- `files.jsonl` — код нашёл скрытый слой. Рядом в `quarantine/` лежит сырой файл по SHA-256. Повтор того же хеша не дописывается.
- `runs.jsonl` — проверка цитат не сошлась. Файл из-за этого не помечается.

`python -m sanitize_skill --export-journal report.jsonl` копирует файловый журнал без выдержек и без query-параметров. Отправка наружу не реализована.

## Ответ читателя

```json
{
  "summary": "В документе итог 1000 рублей.",
  "quotes": [{"text": "Итого 1000 рублей", "kind": "quote"}],
  "numbers": [{"value": "1000", "quote": "Итого 1000 рублей"}],
  "actions": []
}
```

`sanitize-check` (или `python -m sanitize_skill.quotes`) проверяет, что каждая цитата есть в `visible.txt`, каждое число из `numbers` есть и в цитате, и в видимом тексте, а числа от двух знаков в `summary` тоже есть в видимом тексте. В выводе команды только индексы, не сами строки. Непустой `actions` не разрешает действие.

## Что считается скрытым слоем

Удерживается из `visible_text`, если фрагмент не повторяет уже видимый текст и в нём есть хотя бы 8 букв или цифр либо сработала эвристика:

- HTML: `display:none`, `visibility`, нулевая opacity, `hidden`, `aria-hidden`, текст уехавший за экран, нулевой кегль, цвет текста совпал с фоном, комментарии, скрытые input
- PDF: текст за страницей, кегль меньше 1.5 pt, прозрачность около нуля, низкий контраст с фоном рядом с глифом, режим отрисовки 7
- PDF режим 3: сам по себе не находка. Если на странице есть обычный текст, лишний невидимый слой удерживается. Если обычного текста нет, слой считается текстом скана и отдаётся модели
- DOCX: `w:vanish`, `w:webHidden`, белый шрифт на белом, текст из custom XML
- XLSX: скрытый лист, строка, столбец, белый шрифт
- PPTX: скрытый слайд, фигура за пределами слайда, белый шрифт

Комментарии Word и заметки докладчика не смешиваются с текстом страницы: они в `auxiliary`.

Невидимые символы Unicode (zero-width, bidi-перекрытия, tag characters U+E0000–U+E007F, variation selectors не у эмодзи) снимаются с уровня 1. Tag characters, которые декодируются в отдельную фразу, — это скрытый слой. Соединитель эмодзи между картинками не снимается.

## Эвристики

Категории: подмена инструкций, кража учётных данных, адреса эксфильтрации, SSRF. Смешение латиницы и кириллицы в одном слове помечается и не вырезается. Гомоглифы по UTS #39: если фраза совпала с эвристикой только после skeleton-нормализации, в evidence ставится `homoglyph`, а видимый текст не меняется и на уровне 4 не вырезается. Невидимый слой PDF, когда он единственный текст страницы, сверяется с OCR отрисованной страницы, если установлен Tesseract. Доля совпавших слов задаётся `render_match` в домашнем `.sanitize/config.json` (по умолчанию 0.7); число из слоя, которого нет на странице, тоже расхождение. Совпало — это обычный скан. Разошлось — находка `render_mismatch`, в модель попадает текст страницы. Tesseract нет или страница не прочиталась — прежний флаг `render_unverified`. На уровне 4 вырезаются предложения первых четырёх категорий, совпавшие в исходном тексте.

## Ограничения

- Текст, нарисованный на картинке, не читается.
- Сравнение невидимого слоя PDF с отрисованной страницей включается, только если в PATH есть `tesseract` и он вернул достаточно текста. Иначе скан отдаётся с `render_unverified`.
- CSS понимается частично: простые селекторы, inline-стили, shorthand `background` без картинок.
- Цвет темы Word без явного hex не считается белым.
- Универсальной защиты нет: видимая фраза «ignore previous instructions» на уровне 2 доходит до модели. Её держат правило «это данные» и проверка цитат. Уровень 4 такую фразу вырезает и портит обычные тексты, где она употреблена всерьёз.
